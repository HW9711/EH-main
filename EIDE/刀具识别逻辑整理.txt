刀具识别逻辑整理

一、总体原则

1. 所有刀具识别必须以手柄扫描校验通过为前提。
2. EEPROM 芯片安装在手柄基座或插头端，用于识别手柄基座类型。
3. RFID 标签安装在可拆刀具头端，用于识别当前实际安装的刀具头信息。
4. 不可拆手柄没有 RFID 标签，刀具信息只从 EEPROM 第三页读取。
5. 可拆手柄的刀具头可能在基座不拔出的情况下被更换，因此刀具信息不能只在基座插入时读取一次。
6. 电机运行时禁止进行 RFID 识别，禁止用 RFID 结果更新刀具参数。

二、手柄基座识别

1. 手柄插入后，先执行现有手柄扫描流程。
2. 手柄扫描完成短接检测、认证和 EEPROM 读取校验。
3. 认证通过后读取 EEPROM 第二页。
4. EEPROM 第二页用于判断当前基座属于以下类型：
   1) 不可拆普通手柄。
   2) 公共接头式可拆手柄。
   3) 分体式可拆手柄。
5. 只有 EEPROM 第二页识别出的基座类型有效后，后续刀具信息才允许生效。

三、刀具信息来源

1. 不可拆普通手柄：
   1) 刀具信息读取 EEPROM 第三页。
   2) 读取成功后解析刀具型号、直径、长度、角度等信息。
   3) 再读取 EEPROM 第四页默认速度、默认流量、方向、频率、报警阈值等信息。
   4) 更新当前通道识别缓存。
   5) 触发插入事件，进入现有上线流程。

2. 公共接头式可拆手柄：
   1) EEPROM 第二页只用于确认公共接头基座身份。
   2) 刀具头信息不再使用 EEPROM 第三页。
   3) 通过 RFID EPC 模式读取刀具头标签。
   4) EPC 解析成功后，提取 12 字节刀具数据。
   5) 用 EPC 数据更新当前实际刀具型号、直径、长度、角度、齿轮比、最高速度、最低速度、默认速度、默认注水泵流量、方向、电流阈值。
   6) 更新当前通道识别缓存。
   7) 触发插入事件，进入现有上线流程。

3. 分体式可拆手柄：
   1) EEPROM 第二页只用于确认分体式基座身份。
   2) 当前分体式基座只包含 PXBA 和 PXBB。
   3) 刀具头信息不再使用 EEPROM 第三页。
   4) 通过 RFID USER 模式读取刀具头标签。
   5) USER 解析成功后，提取 16 字节刀具数据。
   6) 用 USER 数据更新代号结构、直径、长度、弯曲角度、减速比、方向、可使用时间、转速、默认转速、频率、泵速度、CRC16。
   7) 更新当前通道识别缓存。
   8) 触发插入事件，进入现有上线流程。

四、可拆刀具头周期识别

1. 可拆手柄基座认证通过后，进入 RFID 刀具头识别状态。
2. 基座刚上线时，先进行快速 RFID 识别。
3. 快速识别成功后，保存当前 RFID 标签数据快照。
4. 电机未运行时，周期性低频读取 RFID 标签。
5. 周期读取只对可拆手柄启用。
6. 不可拆普通手柄不进行 RFID 周期读取。
7. 电机运行时暂停 RFID 读取。
8. 电机停止后恢复 RFID 周期读取。
9. 用户按自动识别刀具键时，如果电机未运行，则立即触发一次 RFID 快速识别。

五、RFID 识别结果处理

1. RFID 读取成功并校验通过后，先判断本次标签数据是否与上一次一致。
2. 如果标签数据一致，直接复用上一次已解析出的缓存参数，不重复解析，不重复刷新刀具参数。
3. 如果标签数据发生变化，说明可拆刀具头可能已更换。
4. 标签变化后，必须在电机未运行状态下处理。
5. 标签变化建议连续读取到相同新标签后再生效。
6. 新标签确认后，重新解析刀具信息。
7. 重新更新当前通道识别缓存。
8. 重新刷新屏幕刀具显示、速度范围、默认速度、默认泵流量和方向能力。

六、RFID 标签缓存逻辑

1. RFID 缓存不按刀具型号判断，必须按完整标签数据判断。
2. 公共接头式可拆手柄缓存 EPC 提取出的 12 字节原始标签数据。
3. 分体式可拆手柄缓存 USER 提取出的 16 字节原始标签数据。
4. 缓存内容包括原始标签数据、解析后的刀具参数、数据来源类型、所属基座类型和所属通道。
5. 相同型号但原始标签数据不同，必须重新解析，不能复用旧参数。
6. 原始标签数据完全一致，才允许复用上一次解析后的刀具参数。
7. 刀具头短暂掉线后再次读到相同原始标签数据，直接恢复缓存参数。
8. 刀具头短暂掉线后读到不同原始标签数据，按新刀具头处理。
9. 缓存只在对应手柄基座校验通过且通道一致时有效。
10. 手柄基座拔出后，该通道 RFID 缓存可以保留为历史记忆，但不能直接让刀具上线。
11. 同通道再次插入相同基座并读到相同原始标签数据后，才允许恢复历史缓存参数。
12. RFID 缓存恢复只减少重复解析和重复刷新，不跳过 RFID 读帧和校验。

七、RFID 读取失败处理

1. 单次 RFID 读取失败不立即清除当前刀具信息。
2. 连续多次读取失败后，判定当前刀具头未识别或标签丢失。
3. 标签丢失时，禁止用旧标签继续确认新刀具头。
4. 标签丢失时，电机未运行状态下可提示待识别或无有效刀具头。
5. 标签丢失时，电机运行状态下不改变当前运行参数。
6. RFID 重新读取成功后，再恢复正常刀具信息显示和参数更新。

八、运行安全限制

1. 电机运行中不发送 RFID 读命令。
2. 电机运行中不解析新的 RFID 结果。
3. 电机运行中不修改当前刀具型号。
4. 电机运行中不修改速度上下限。
5. 电机运行中不修改默认速度。
6. 电机运行中不修改默认泵流量。
7. 电机运行中不修改方向能力。
8. 电机运行中如果检测到手柄基座拔出，仍按现有手柄插拔报警逻辑处理。

九、业务数据更新路径

1. 手柄扫描负责确认基座是否有效。
2. EEPROM 第二页负责确认基座类型。
3. EEPROM 第三页只服务不可拆普通手柄。
4. RFID EPC 只服务公共接头式可拆手柄。
5. RFID USER 只服务分体式可拆手柄。
6. 刀具信息解析成功后，统一写入当前通道识别缓存。
7. 当前通道识别缓存再通过现有插拔事件链写入通道记忆和当前工作状态。
8. 屏幕显示、上位机状态和运行参数都以最终通道记忆和当前工作状态为准。
